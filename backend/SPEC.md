# Reserve Pay Guardrail - Technical Specification

## Overview
Reserve Pay Guardrail provides risk mitigation, payment guardrails, and reserve management for online payments.

## Architecture
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Testing**: Vitest

## Folder Structure
- `/lib` - Core business logic and utilities
- `/app/api` - API endpoints for payment guardrails and reserve calculations
- `/app` - UI components for dashboards and guardrail controls
- `/lib/__tests__` - Unit and integration tests for core logic
